- **만든 사람**: 신 / 노 / 윤 / 권 / 어 중 하나

- **만든 날**: YYYY-MM-DD

## 왜 만들었나
어떤 일을 할 때 무엇이 불편했는지. "매번 X를 손으로 했다", "Y를 빠뜨려서 Z가 생겼다" 처럼 구체적으로.

## 근거
이 에이전트가 그 불편을 줄여 준다고 본 이유. 실제로 겪은 사례, 걸린 시간, 참고한 자료나 팀 규칙.

## 어떻게 다루나
- **부르는 때**: 언제 쓰면 되는지
- **부르는 말 예시**: "shin-prd-reviewer로 이 PRD 봐줘"
- **넣는 것**: 파일, 링크, 붙여 넣는 글 등
- **받는 것**: 결과가 어떤 모양으로 나오는지
- **쓰는 도구**: 읽기만 하는지, 파일을 고치는지

## 한계와 주의
잘 못하는 것, 결과를 사람이 꼭 확인해야 하는 부분.
