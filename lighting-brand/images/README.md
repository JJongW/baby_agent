# 사진

모든 페이지가 같이 쓰는 사진. 전부 **ChatGPT 이미지 생성**으로 만들었다 (실제 브랜드 사진 아님). 각자 페이지에 쓰면 `showcase.md` 출처 칸에 "ChatGPT 이미지 생성, `images/...`"라고 적는다.

## products/ 제품 켜짐, 꺼짐 한 쌍 (담당: 정연)
- 이름: `<제품 코드>-on.webp`, `<제품 코드>-off.webp` (코드는 `common/products.js`의 `code`)
- 크기: 1200×1500 (4:5, 제품 카드 사진 자리 `.ph`와 같은 비율)
- 두 장은 같은 방, 같은 구도라 겹쳐 놓고 켜짐 사진의 투명도만 바꾸면 켜고 끄는 효과가 된다 (`pages/product/CLAUDE.md`)
- 같은 종류는 같은 틀로 잘라서, 목록에 나란히 두면 실제 크기 차이가 보인다. 테이블과 펜던트는 같은 크기의 틀, 스탠드는 키가 커서 넓은 틀

| 코드 | 이름 | 있음 |
| --- | --- | --- |
| T-01 | 달 테이블 | 켜짐, 꺼짐 |
| T-02 | 작은 등 테이블 | 켜짐, 꺼짐 |
| S-01 | 긴 기둥 스탠드 | 켜짐, 꺼짐 |
| P-02 | 큰 달 펜던트 | 켜짐, 꺼짐 (사진은 지름 약 50cm. `products.js`의 80cm를 50cm로 바꿔야 맞음) |

아직 없음: T-03, S-02, S-03, P-01, P-03. 없는 제품은 지금처럼 회색 자리(`.ph`)로 둔다.

## concept/ 분위기 컷
- `concept-T-01-hero.webp`: 1920×1080 (16:9). 홈 첫 화면용. 왼쪽 나무 면에 문구를 얹을 수 있다 (담당: 상경)
- `concept-T-01.webp`: 1536×1024 (3:2) 원본. 스토리, 매거진 본문용
- `concept-T-01-T-02-hero.webp`: 1920×1080 (16:9). 다다미 위 T-01과 T-02. 오른쪽 다다미 면에 문구 자리
- `concept-T-01-T-02.webp`: 1536×1024 (3:2) 원본
