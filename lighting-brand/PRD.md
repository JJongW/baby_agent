# PRD: 종이 조명 브랜드 페이지 ONDO (온도)

> 작성: 신 (PO), 2026-11-11, 상태: **초안** (팀 리뷰 전)
> 디자인 결정은 어(상경)의 의견을 따른다. 1차는 대략적인 디자인(와이어프레임 수준)으로 만든다.

## 1. 요약

대나무 살에 한지를 씌운 조명을 파는 **가상의 브랜드 ONDO(온도)** 소개 사이트를 만든다.
디자인은 **일본의 덜어내는 디자인**으로 간다. 색, 장식, 문구를 줄이고 빈 곳과 빛이 주인공이 되게 한다.
철학은 **와비사비**다. 완벽하지 않은 것, 손때와 결이 남은 것, 시간이 지나며 바래는 것을 아름답게 본다. 반듯하게 다듬은 광택보다 종이의 결, 고르지 않은 빛, 넉넉한 빈 곳을 보여 준다.
홈, 제품, FAQ, 스토리, 매거진 다섯 페이지를 다섯 명이 하나씩 맡고, 한 사이트로 묶어 Render에 배포한다.
분위기는 이사무 노구치의 Akari 종이 조명 판매 페이지를 참고하되, 이름, 사진, 글은 모두 우리가 새로 만든다.

## 2. 사람과 역할

| 사람 | 레포 폴더 | 맡은 일 | 메모 |
| --- | --- | --- | --- |
| 신 | `shin` | PO, 이 문서, FAQ 페이지, 공통 틀과 배포 | 페이지들을 한 사이트로 묶는다 |
| 상경 | `eo` (어) | 홈 페이지, **디자인 방향 결정** | 색, 글꼴, 여백 규칙을 정한다 |
| 정연 | `yoon` (윤) | 제품 페이지, 제품 데이터 | 홈도 이 데이터를 쓴다 |
| 지혜 | 김 | 스토리 페이지 | **레포 사람 목록에 없음. 확인 필요** (노 자리인지) |
| 지영 | `kwon` (권) | 매거진 페이지 | |

## 3. 배경

- 할인 레이더 다음 팀 과제다. 이번에는 데이터 분석이 아니라 **브랜드를 보여 주는 사이트**를 만든다.
- 조명은 사진 한 장으로 분위기가 전해지는 상품이라, 페이지 구성과 디자인 연습에 알맞다.
- 다섯 명이 각자 한 페이지를 맡으면, 디자인 규칙을 함께 지키는 연습도 된다. 할인 레이더 때처럼 각자 만들고 신이 합친다.

## 4. 목표

**목표:** 처음 온 사람이 1분 안에 "이 브랜드가 무엇을 파는지, 왜 특별한지"를 알고, 원하는 조명이나 답을 찾게 한다.

**핵심 결과 (1차 배포 기준)**
1. 다섯 페이지가 같은 메뉴, 색, 글꼴로 Render 주소 하나에 올라간다
2. 처음 보는 사람 5명에게 시켜 봤을 때, 5명 중 4명 이상이 30초 안에 해낸다
   - 가장 싼 테이블 조명 찾기
   - "전구는 어떤 걸 써요?" 답 찾기
3. 모든 페이지가 휴대폰 폭(375px)에서 옆으로 밀리지 않는다
4. 첫 화면이 3초 안에 뜬다 (사진 용량 관리)

## 5. 누구를 위한 사이트인가

- **방을 따뜻하게 바꾸고 싶은 사람:** 형광등 대신 은은한 빛을 찾는다. "우리 방에 어떤 크기가 맞지?"가 궁금하다
- **선물을 고르는 사람:** 집들이, 결혼 선물로 오래 쓸 물건을 찾는다. 가격대와 포장이 궁금하다
- **만든 이야기에 끌리는 사람:** 손으로 만든 물건, 재료와 과정을 알고 사고 싶다

제약: 실제로 팔지 않는다. 결제, 장바구니, 로그인은 없다.

## 6. 주는 가치

| 고객이 하려는 일 | 겪는 불편 | 이 사이트가 주는 것 |
| --- | --- | --- |
| 방에 맞는 조명 고르기 | 사진만 봐서는 크기와 빛이 감이 안 온다 | 크기(cm)를 적고, 켜기 버튼으로 켰을 때 모습을 보여 준다 |
| 궁금한 점 풀기 | 전구, 관리, 배송 답을 찾아 헤맨다 | FAQ를 주제별로 묶고 검색을 둔다 |
| 믿고 사기 | 어디서 어떻게 만들었는지 모른다 | 재료(한지, 대나무)와 만드는 과정을 스토리로 보여 준다 |
| 꾸미는 법 알기 | 사도 어디에 둘지 모른다 | 매거진에 공간별 배치 예시를 싣는다 |

## 7. 해결책

### 7.1 사이트 구조

```
공통 머리: 로고 | 홈  제품  스토리  매거진  FAQ
  ├─ 홈        첫 화면 사진 → 대표 제품 3개 → 스토리 맛보기 → 최신 매거진 3개
  ├─ 제품      종류 필터, 가격순 정렬, 제품 카드 목록
  ├─ 스토리    브랜드가 생긴 이야기 → 재료 → 만드는 과정 → 만드는 사람
  ├─ 매거진    글 카드 목록 → 글 한 편 보기
  └─ FAQ       주제 묶음 → 질문을 누르면 답이 펼쳐짐, 검색
공통 바닥: 브랜드 한 줄, 메뉴, "가상 브랜드, 판매하지 않음" 안내
```

### 7.2 페이지별 기능 (1차)

**공통 (신)**
- 머리 메뉴와 바닥은 모든 페이지가 같은 것을 쓴다. 지금 보고 있는 메뉴는 표시한다
- 디자인 규칙(색, 글꼴, 여백)은 어가 정해 공통 스타일 파일 하나로 둔다. 각자 따로 색을 정하지 않는다

**홈 (상경)**
- 첫 화면: 불 켜진 조명 사진을 크게, 브랜드 한 줄 소개
- 대표 제품 3개 (제품 데이터에서 가져옴), 누르면 제품 페이지로
- 스토리 맛보기 한 단락, 최신 매거진 글 3개

**제품 (정연)**
- 제품 카드: 사진, 이름, 크기(cm), 가격
- **켜기, 끄기 효과:** 끄면 어둡고, 켜면 따뜻한 빛이 번지며 밝아진다. 누르는 버튼으로 켜고 끈다 (휴대폰에서도 되게). 조명 브랜드의 핵심 경험
- 종류 필터: 테이블, 스탠드, 펜던트(천장에 다는 것)
- 정렬: 가격 낮은 순, 높은 순
- 1차 제품 수: 9~12개. 이름은 Akari처럼 짧은 코드로 지을 수 있다 (예: T-01, P-03). 이름 규칙은 어와 정한다
- 제품 데이터는 파일 하나(제품 목록)에 모아 홈도 같이 쓴다

**FAQ (신)**
- 주제 4개: 주문과 배송, 전구와 전기, 관리와 수리, 교환과 반품
- 질문을 누르면 답이 펼쳐진다. 한 번에 여러 개를 열 수 있다
- 맨 위에 검색칸: 질문과 답에서 낱말을 찾아 걸러 보여 준다
- 1차 질문 수: 주제마다 3~5개

**스토리 (지혜)**
- 브랜드가 생긴 이야기 (가상)
- 재료: 한지, 대나무 살, 왜 이 재료인지
- 만드는 과정: 3~5단계를 사진과 짧은 글로
- 만드는 사람 소개 (가상 인물)

**매거진 (지영)**
- 글 카드 목록: 대표 사진, 제목, 분류(공간 꾸미기, 인터뷰, 관리 팁)
- 글 한 편 보기 화면 1개 이상
- 1차 글 수: 3~4편

### 7.3 기술 (제안, 팀 확인 필요)

- **정적 사이트**(HTML, CSS, 조금의 JavaScript)로 만들고 Render의 Static Site로 배포한다. 서버가 필요 없고, 다섯 명이 각자 파일 하나씩 맡기 쉽다
- 폴더: `lighting-brand/pages/<페이지>/`, 공통 스타일과 머리, 바닥은 `lighting-brand/common/`
- Render 설정: Root Directory `lighting-brand`, 무료 플랜
- 사진: Noguchi, Akari의 사진과 글은 쓰지 않는다. AI로 만든 이미지나 무료 사진(출처 기록)만 쓴다. 사진 한 장 300KB 이하

### 7.4 가정 (아직 확인 안 됨)

- 다섯 명 모두 HTML, CSS로 페이지 하나를 만들 수 있다 (어렵다면 공통 틀을 신이 먼저 만들어 준다)
- 실제 브랜드를 참고만 하고 이름, 사진, 글을 새로 만들면 공개 배포해도 문제가 없다
- 같은 이름(ONDO, 온도)의 조명 브랜드가 있는지 확인이 필요하다
- 김 지혜 님은 노 님 자리를 맡는다 (확인 필요)
