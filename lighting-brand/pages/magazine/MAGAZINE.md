# ONDO 매거진 가이드

매거진 글과 화면을 만들 때 지킬 공통 규칙(Part 1)과 글별 세부 내용(Part 2).
작업 규칙은 [CLAUDE.md](CLAUDE.md), 사이트 전체 규칙은 [../../CLAUDE.md](../../CLAUDE.md)가 먼저다. 이 문서는 매거진 안에서만 쓰는 세부 약속이다.

---

## Part 1. 공통 규칙

### 1. 톤

- 와비사비와 덜어내는 디자인에 맞춰 조용하고 낮은 목소리로 쓴다. 권하지 않고, 곁에서 들려주듯 쓴다.
- 존댓말(해요체)을 쓰고, 한 문장은 짧게 한다.
- 느낌표와 이모지는 쓰지 않는다. 마침표로 끝낸다.
- "최고, 완벽, 반드시" 같은 단정과 과장을 피한다. 불완전함과 시간이 남기는 흔적을 좋은 것으로 말한다.
- 제품을 팔지 않는다. 가상 브랜드이므로 가격과 구매 유도 문구도 넣지 않는다.
- 글 길이는 본문 400~600자, 단락 3~5개로 한다.
- 빛은 "밝다"보다 촉각으로 쓴다: 번지다, 스미다, 낮아지다, 바래다.

**쓰지 않는 말**

감성적인 · 아늑한 · 프리미엄 · 전통의 멋 · 힐링 · 지금 만나보세요

| 전 | 후 |
| --- | --- |
| 감성적인 한지 조명으로 아늑한 공간을 완성해 보세요! | 저녁에는 천장등을 끄고 작은 불빛 하나만 켜 두어요. |
| 전통 한지의 멋을 담은 프리미엄 조명 | 한지는 해마다 조금씩 바래요. 그 빛깔을 따라 불빛도 깊어져요. |

### 2. 글 구조

```
분류(eyebrow)
제목
한 줄 요약
대표 사진
본문 (소제목은 글당 최대 2개)
마무리 한 줄
다음 글 →
목록으로 돌아가기
```

- 모든 글 끝에 "다음 글 →" 링크를 하나 둔다. 마지막 글(No.3)은 첫 글(No.1)로 잇는다.
- "목록으로 돌아가기" 링크를 항상 둔다.

### 3. 레이아웃

색, 글꼴, 간격은 `common/style.css`의 토큰만 쓴다 ([DESIGN.md](../home/DESIGN.md) 시안 v3). 새 색, 새 간격 값을 만들지 않는다.

- **목록(`index.html`):** 카드 3열(데스크톱), 2열(960px 이하), 1열(640px 이하). 카드는 4:5 사진, 분류(`.eyebrow`), 제목(`--text-md`, 굵기 500)만 넣는다. 가운데 카드를 내리는 식의 어긋남 없이 3장이 같은 높이에 놓인다.
- **카드와 구분:** 그림자, 테두리, 둥근 모서리(`--radius` 0)를 쓰지 않는다. 카드 사이는 `--space-4`(세로), `--space-3`(가로).
- **글 페이지 틀:** 제목(`h1`) → 한 줄 요약 → 대표 사진(3:2) → 본문 → 마무리 한 줄 → 이동 링크.
- **본문 배치:** 사진과 글을 좌우로 번갈아 놓는다. 사진 왼쪽 글 오른쪽, 다음 줄은 글 왼쪽 사진 오른쪽(`.row`, `.row.flip`). 960px 이하에서는 한 줄로 쌓고 사진이 먼저 나온다.
- **간격:** 줄과 줄 사이, 대표 사진 아래는 `--space-section`, 사진과 글 사이는 `--space-5`. 제목과 요약, 요약과 사진 사이는 `--space-2`, `--space-5`.
- **글자:** 큰 제목은 `h1`(마루 부리), 소제목은 `h2`(마루 부리), 본문은 `--text-md`, 요약과 마무리 한 줄은 `--text-lg`, 가상 인물 안내는 `--text-sm`. 굵은 글씨로 강조하지 않는다.
- **글 한 줄 폭:** `--text-width`(640px) 이하. 본문 최대 폭은 `--page-width`.
- **색:** `--ink`, `--ink-soft`, `--hanji-deep`(사진 자리)만 쓴다. `--earth`는 쓰지 않는다. 옛 이름(`--paper`, `--space`)은 쓰지 않는다.
- **링크:** 이동 링크는 공통 `.text-link`(밑줄 1px)를 쓴다. 누르는 영역은 44px 이상이다.
- **사진 비율:** 대표 사진은 3:2, 카드와 본문 사진은 4:5(원본이 가로인 사진은 3:2 허용: 글 2와 글 3의 본문 사진 각 한 장). DESIGN.md는 본문 사이 사진을 3:2로 적고 있어 상경과 확정 때 맞춘다.
- **사진 위에 글자를 얹지 않는다.**
- **접근성:** 모든 이미지에 `alt`를 쓴다. 키보드 초점 표시는 공통 `:focus-visible`이 맡는다(페이지에서 따로 지우거나 만들지 않는다).
- **휴대폰:** 375px 폭에서 옆으로 밀리지 않게 한다.

### 4. 사진 (AI 생성)

- 공통 사진(`../../images/`)을 먼저 쓴다. 복사하지 않고 `../../images/...` 경로로 불러온다. 공통 사진으로 안 되는 장면만 직접 만들어 `pages/magazine/images/`에 둔다.
- 출처는 공통 사진은 "ChatGPT 이미지 생성, `images/...`", 직접 만든 사진은 사용한 도구 이름을 `showcase.md` 표에 적는다.
- Noguchi, Akari 같은 실제 브랜드의 사진, 이름, 글은 쓰지 않는다.
- 한 장은 300KB 이하로 한다.
- 천장등이나 형광등이 켜진 컷은 쓰지 않는다. 한지를 지나 번진 따뜻한 빛만 보인다.
- 불이 닿지 않은 곳은 어둡게 남긴다. 완전한 검정은 아니다.
- 글자 오버레이, 웃는 정면 인물, 스톡 같은 연출은 쓰지 않는다.
- 생활의 흔적은 한 장면에 하나만 둔다(찻잔, 책, 슬리퍼 중 하나).

### 5. 파일 규칙

| 파일 | 내용 |
| --- | --- |
| `index.html` | 글 카드 목록 |
| `article-1.html` | 글 1. 공간 꾸미기 |
| `article-2.html` | 글 2. 인터뷰 |
| `article-3.html` | 글 3. 관리 팁 |
| `images/` | 이미지. 영어 소문자, 숫자, `-`로 이름을 짓는다 (예: `room-evening.jpg`) |
| `showcase.md` | 작품 게시. 다 만들면 채워 PR에 올린다 |

- 모든 HTML은 `common/style.css`를 `<link>`로 연결한다.
- 매거진에만 필요한 모양은 별도 CSS 파일 없이 각 HTML의 `<style>` 안에 쓴다. 글 3편의 글용 CSS는 같은 내용을 복사해서 쓰고, 고칠 때는 세 파일을 함께 고친다.
- 각 HTML의 `<header data-site-header>`, `<footer data-site-footer>`, 맨 아래 `<script>` 두 줄은 지우지 않는다. 글 파일의 틀(`<head>`, 머리, 바닥, 스크립트)은 `index.html`과 똑같이 둔다.
- 글 파일의 `<body>`에도 `data-page="magazine"`을 둔다(메뉴에서 매거진이 표시된다).

### 6. 건드리지 않는 것

- `common/`, 다른 페이지 폴더, `PRD.md`, `README.md`, 상위 `CLAUDE.md`
- `common/`을 바꾸고 싶으면 고치지 말고 신(PO)에게 요청한다.

### 7. 홈과 연결

- 홈 담당 상경이 "최신 글 3개"를 보여 준다. 글 제목과 링크가 확정되면 상경에게 알린다.
- 링크 형식: `/pages/magazine/article-1.html`

## Part 2. 글별 세부 내용

### 글 1. 공간 꾸미기: 퇴근 후 한 시간, 방의 불을 낮추는 일

- **파일:** `article-1.html`
- **분류:** 공간 꾸미기
- **한 줄 요약:** 천장등을 끄고 작은 불빛 하나만 켜 보는 저녁.
- **구성:** 퇴근 직후의 형광등 방 → 테이블 조명 하나로 바꾸는 법 → 두는 높이와 벽과의 거리 → 빛이 번지는 모습
- **핵심 메시지:** 밝기를 줄이면 방이 넓어 보이고 마음이 가라앉는다.
- **사진:** 대표 - 어두운 방에서 불이 켜진 종이 조명 / 본문 - 침대 옆이나 책상 위 배치
- **마무리 한 줄:** 오늘 밤은 불을 하나만 켜 보세요.
- **다음 글:** 글 2

### 글 2. 인터뷰: 이 년째 한지 조명과 사는 사람, 정하은

- **파일:** `article-2.html`
- **분류:** 인터뷰
- **인물:** 정하은(가상). 만드는 사람이 아니라 **조명을 사서 쓰는 사람**이다. 작은 집에 혼자 살고, 창가와 방 구석에 한지 조명을 하나씩 두고 이 년째 쓴다.
- **한 줄 요약:** 조명 하나와 이 년을 지낸 저녁을 묻는 짧은 대화.
- **구성:** 인물 소개 두 줄 → 질문 4개와 답(Q/A 형식) → 마무리
- **질문:** 주로 언제 켜세요 / 쓰면서 달라진 점이 있나요 / 낮에는 어떤가요 / 아쉬운 점이 있다면요
- **핵심 메시지:** 조명 하나가 저녁을 느리게 바꾸고, 바래는 한지도 일상의 일부가 된다.
- **사진:** 대표 - 다다미 위의 조명 두 개(`concept-T-01-T-02`) / 본문 - 불이 꺼진 테이블 조명(`T-01-off`) / 목록 카드 - `concept-T-01-T-02`를 4:5로 잘라 사용
- **주의:** 가상 인물이라는 점이 드러나게 쓴다. 제작자(장인, 만드는 사람)는 다루지 않는다. 그 이야기는 스토리 페이지 담당이다.
- **다음 글:** 글 3

### 글 3. 관리 팁: 누렇게 바래는 것도 조명의 시간입니다

- **파일:** `article-3.html`
- **분류:** 관리 팁
- **한 줄 요약:** 한지가 해를 따라 깊어지는 것을 받아들이는 관리법.
- **구성:** 바램은 흠이 아니라는 이야기 → 먼지 털기 → 습기와 직사광선 피하기 → 찢어졌을 때 덧붙이기
- **형식:** 관리 방법은 번호 목록(3~4개)으로 짧게 쓴다.
- **핵심 메시지:** 새것처럼 유지하려 하지 말고, 함께 낡아 가는 법을 알려 준다.
- **사진:** 대표 - 바랜 한지의 결 클로즈업 / 본문 - 먼지 터는 손(선택)
- **주의:** 실제 수리나 보증을 약속하지 않는다. FAQ 페이지의 관리와 수리 답변과 내용이 어긋나지 않게 신(FAQ 담당)과 확인한다.
- **다음 글:** 글 1
