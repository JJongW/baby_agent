# sources: 조원별 데이터 폴더

폴더 하나가 조원 한 명(또는 수집처 하나)이다. 앱은 `adapter.py`가 있는 폴더를 자동으로 사이드바에 올린다.

```
sources/<이름>/
  adapter.py   필수. 아래 약속을 지킨다 (조원 코드 모양이 제각각이라 신이 맞춰 쓴다)
  data/*.csv   수집 결과. 앱은 이것만 읽는다
  crawl*.py    조원이 쓴 수집 코드 그대로 (API, requests, Playwright 무엇이든)
  style.css    선택. 이 조원 항목을 골랐을 때만 덧입힌다
```

## adapter.py 약속
```python
TITLE = "노트북"           # 사이드바 이름
SOURCE = "다나와"          # 수집처
METHOD = "정적 크롤링"     # API / 정적 크롤링 / Playwright
UNIT = "원"                # 선택. 원화가 아니면 적는다(예: "달러"). 전체 보기 합계에서 빠진다
NOTE = "..."               # 선택. 데이터를 볼 때 알아야 할 점. 표 화면에 보인다

def show(st) -> None:       # 선택. 있으면 이 조원 항목을 골랐을 때 공통 화면 대신 이걸 그린다 (예: sources/eo)
    ...

def load() -> pd.DataFrame:  # 아래 열을 돌려준다. 크롤링을 여기서 다시 하지 않고 CSV를 읽는다
    ...
```

| 열 | 뜻 | 없으면 |
| --- | --- | --- |
| `name` | 상품 이름 | 필수 |
| `category` | 카테고리 | "기타" |
| `price` | 지금 파는 값(원) | 필수, 없으면 그 줄은 빠진다 |
| `original_price` | 할인 기준 값(정가, 또는 조가 정한 기준값) | 할인율 0 |
| `review_count` | 리뷰 수 | 리뷰 조건 검사를 건너뜀 |
| `url` | 상품 링크 | 링크 버튼이 안 보임 |
| `note` | 조건 (카드 결제 시, 쿠폰 적용가 등) | 빈칸 |

할인율, "확인 필요" 표시는 `radar.py`가 모두에게 똑같이 계산한다.
정가가 하나도 없어 할인율을 모르는 데이터(예: 권의 아이폰 출시가)는 할인 비교 대신 `load()` 표를 그대로 보여 준다.

## 크롤링을 앱에서 다시 하지 않는 이유
Playwright는 배포 서버(Streamlit Cloud)에 브라우저가 없어 돌지 않고, 시연 중에 수집처가 막힐 수도 있다.
수집은 각자 컴퓨터에서 하고 결과 CSV만 올린다. 바꿀 시점: 실시간 가격이 꼭 필요해지면 API 수집처만 앱에서 부르게 한다.
