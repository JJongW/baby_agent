# 변경 내용: `iphone_models.csv` → `iphone_crawl/iphone_specs.csv`

> 위키백과로 만든 `iphone_models.csv`(PR #22로 머지)를 GSMArena에서 모은 `iphone_crawl/iphone_specs.csv`로 바꾼 내용입니다.
> 표의 `전 → 후`에서 **굵은 글씨**가 바뀐 값입니다.

## 0. 배경: 무엇이 최신이고, 무엇이 필요 없어졌나

- **`iphone_crawl/`가 새로 작업한 최신 내용입니다.** GSMArena 첫 페이지에서 iPhone만 골라 상세 스펙(가격, 출시일, 화면, 칩셋, 출시 iOS)을 `iphone_specs.csv`로 정리합니다.
- **이전에 한 위키백과 크롤링은 더 이상 필요하지 않습니다.** 아이폰 정보는 앞으로 `iphone_crawl/iphone_specs.csv`를 기준으로 씁니다. 그래서 위키백과 결과인 `iphone_models.csv`를 새 CSV로 바꿨습니다.
- **최종 버전은 `iphone_specs.csv`입니다.** 레포 기준 위치는 아래와 같습니다.

```
members/kwon/wiki-iphone-crawl/
├── CHANGES.md                    ← 이 문서
└── iphone_crawl/                 ← 최신 작업 (이것을 쓴다)
    ├── iphone_specs.csv          ← 최종 결과 (iPhone 21개)
    ├── save_iphone_csv.py        ← 결과를 만드는 스크립트
    ├── iphone.py                 ← 요청 담당 (3~5초 대기, 캐시, 403/429면 중단)
    └── .gitignore                ← 받은 원본 HTML(cache_iphone/)은 올리지 않음
```

- 위키백과 크롤링 파일(`step1_download.py`, `step2_download_models.py`, `step3_parse.py`, `wikipedia-crawl-guide.md`, `data/`)은 이 변경에서 **지우지 않았고**, 쓰지 않는 기록으로 남아 있습니다.

## 5. 주의할 점

- **가격 값의 성격이 다릅니다.** 위키 CSV의 가격은 미국 시작가이고 문서에 근거를 적었습니다. GSMArena 가격은 나라별 가격을 환산한 값이 섞여 있어서, 같은 모델도 값이 다릅니다. 예를 들어 아이폰 16은 위키 799, GSMArena 543.9입니다. 정확한 정가가 필요하면 `가격 근거`가 있던 위키 값을 쓰세요.
- **iPhone Duo 가격 1999는 GSMArena 값이 아닙니다.** GSMArena 상세 페이지에 가격이 없어서 출시 보도(미국 256GB 기준)를 보고 직접 넣었습니다.
- **출처 표기가 바뀝니다.** 위키 CSV의 `라이선스`(CC BY-SA 4.0), `출처 URL`, `수집일`, `가격 근거` 열이 없어집니다. 새 CSV에는 `주소` 열만 있습니다.
- **약관.** GSMArena 약관은 서면 허락 없는 재배포를 금지합니다. 이 CSV는 개인 학습용이며, 공개 저장소에 올리면 약관상 문제가 될 수 있다는 점을 알고 올린 것입니다.
- **위키백과 쪽 파일은 더 이상 쓰지 않습니다.** `step3_parse.py`를 다시 실행하면 지운 `iphone_models.csv`가 다시 생성되고, `wikipedia-crawl-guide.md`의 파일 표도 아직 `iphone_models.csv`를 설명하고 있습니다. 이 둘은 이번에 고치지 않았으니 실행하거나 참고할 때 주의하세요.
- 새 CSV는 `iphone_crawl/save_iphone_csv.py`로 다시 만들 수 있습니다 (`iphone_crawl/iphone.py`를 불러 쓰며, 받은 페이지는 `iphone_crawl/cache_iphone/`에 저장되지만 `.gitignore`로 올라가지 않습니다).
