# UI & 디자인 시스템 검토 결과: `members/shin/tarot/prototype.html`

**점검 범위와 기준**
- **읽은 범위:** 431줄 전체를 Grep으로 읽었습니다. 이 환경에 ReadFile 도구가 없어 Grep을 썼고, 읽기 오류는 없었습니다.
- **검토 방식:** 코드만 읽었고 브라우저 렌더링은 하지 않았습니다. 레이아웃 항목은 코드 기준 판단이라 실제 화면 확인이 필요합니다.
- **판단 기준:** 레포에 별도 디자인 시스템 문서가 없어, 이 파일의 `:root` 토큰과 5대 체크리스트를 기준으로 삼았습니다.
- **수정 여부:** 파일을 수정하지 않았습니다.

## 1. 5대 핵심 체크리스트 요약
- [ ] 1. 시맨틱 컬러 토큰: 하드코딩 55건 (CSS 15건, SVG 40건)
- [ ] 2. 4/8px 스페이싱 배수: padding·margin·gap 규격 외 14건 (10개 줄), 위치값 4건
- [ ] 3. 타이포그래피 스케일: 개선 필요 (스케일 토큰 없음, 고정 크기 6종과 clamp 3종)
- [ ] 4. 인터랙션 요소 규격: 개선 필요 (radius 혼용, 높이 미지정, 폰트 누락 1건)
- [ ] 5. 예외/상태 화면 대응: 보완 필요 (문구와 동작 불일치, 타이머 경합, 스크롤 잘림 위험)

위 표의 첫 두 줄은 CSS 안의 값이고, `--pet-*`는 SVG 일러스트 전용 값입니다. 일러스트 색은 토큰화 우선순위를 낮춰도 됩니다. 다만 위쪽 표의 SVG 18건처럼 기존 토큰과 값이 같은 색은 함께 바꾸는 편이 좋습니다.

**토큰 정의 문제**
- **미사용 토큰:** `--red-deep`, `--red-soft`, `--white`, `--muted`는 정의만 있고 쓰이지 않습니다. `--red-deep`은 위 파생 작업으로 살아나고, 나머지는 쓸 계획이 없으면 지웁니다.
- **무효화된 토큰 (L57~58):** `border: 1px solid var(--line)`을 바로 다음 줄의 `border-color: rgba(...)`가 덮어써서 `--line`이 사실상 쓰이지 않습니다. `--line-on-dark`를 새로 만들어 한 번만 선언할 것을 권장합니다.

- **L57의 13px은 숫자만 바꾸면 안 됩니다.** 13px 패딩에 테두리 1px을 더하면 버튼 패딩 14px과 같아져서, 입력창과 버튼 높이를 맞추려던 값으로 보입니다. 12px로만 바꾸면 높이가 어긋나므로 위 표처럼 고정 높이로 바꾸는 편이 안전합니다.

### 개선 제안: 타이포그래피

- **스케일 토큰 없음:** 고정 크기 12, 13, 14, 15, 16, 18px과 clamp 3종이 흩어져 있습니다. 아래처럼 묶을 것을 권장합니다.

| 토큰 | 값 | 현재 사용처 |
|---|---|---|
| `--text-h1` | `clamp(30px, 7vw, 46px)` | L48 |
| `--text-h2` | `clamp(24px, 5vw, 32px)` | L152, L287, L323 |
| `--text-body` | `16px` | L49, L52, L58, L153 |
| `--text-body-sm` | `14px` | L139, L156 |
| `--text-caption` | `12px` | L47, L135, L138, L151, L155, L169 |

- **같은 위계인데 값이 다름:** L152는 최대 30px, L287과 L323은 최대 32px입니다. L287과 L323은 `h1`의 크기를 인라인으로 덮어쓰고 있어 클래스로 빼는 편이 좋습니다.
- **본문보다 큰 미션 문구:** `#rMission`(L313)은 크기 지정이 없어 기본값 16px을 받습니다. 그래서 15px인 `.r-body`(L153)보다 커지고, 체크박스 라벨은 14px입니다. 의도한 강조라면 명시하고, 아니라면 맞춥니다.
- **폰트 패밀리 직접 지정:**
  - Cinzel 5곳(L47, L135, L138, L151, L164)과 Pretendard 3곳(L39, L52, L58)에 직접 쓰여 있습니다. `--font-display`, `--font-sans`로 묶을 것을 권장합니다.
  - 대체 폰트 지정도 L39와 L52·L58이 서로 다릅니다.
- **letter-spacing 5종:** `.1`, `.14`, `.2`, `.24`, `.32em`이 섞여 있습니다. 2~3단계로 줄일 것을 권장합니다.
- **안 쓰는 폰트 로드 (L7):**
  - Cormorant Garamond는 `--serif`의 첫 번째 폰트지만, 이 폰트가 적용되는 제목이 모두 한글이라 실제로는 Noto Serif KR로 표시될 가능성이 높습니다.
  - Cormorant의 이탤릭, Cinzel 600, Noto Serif KR 500은 코드에서 쓰는 곳을 찾지 못했습니다.

### 수정 권장: 인터랙션 요소 형태

- **L169 `.restart` 폰트 누락:** `font-family`가 없고 `button`은 폰트를 상속하지 않습니다. 이 버튼만 Pretendard가 아닌 브라우저 기본 폰트로 보입니다. `font-family: inherit`를 추가합니다.
- **L89, L132 / L57, L154 radius 혼용:** 카드는 14px, 입력창과 미션 박스는 12px입니다. `--radius-md: 12px`로 통일하고, 버튼의 `999px`는 `--radius-full`로 둘 것을 권장합니다.
- **L52, L57 높이 미지정:** 버튼과 입력창 높이가 패딩과 줄 높이의 계산 결과에 의존합니다. `--control-h: 48px`로 고정할 것을 권장합니다.
- **L50~54 상태 스타일 없음:** `.btn`에 `:hover`와 `:active`가 없고, 파일의 어떤 인터랙션 요소에도 없습니다. 주요 버튼부터 정의할 것을 권장합니다.
- **L137, L159 카드 내부 고정 크기:**
  - 카드는 220px에서 150px로 줄지만, 일러스트는 120px로 고정입니다. 카드 대비 비율이 약 55%에서 80%로 커져 프레임에 거의 닿을 수 있습니다.
  - `width: 55%; height: auto`처럼 비율로 지정할 것을 권장합니다.
- **L53, L90, L123~125, L133 그림자 규격 없음:** 그림자 정의가 제각각입니다. `--shadow-card`, `--shadow-raised`로 묶을 것을 권장합니다.
- **L32~34, L264~266 `!important` 의존:** 펫 크기를 인라인으로 지정해서 미디어쿼리가 `!important`로 덮어쓰고 있습니다. 크기를 클래스로 옮기면 `!important`가 필요 없습니다.
- **L157 체크박스 크기:** 22px은 배수 체계 밖이므로 24px을 권장합니다.
- **L89, L129, L159 카드 폭:** 200, 220, 150px의 3가지 값이 흩어져 있습니다. `--card-w-*`로 정리할 것을 권장합니다.

### 보완 필요: 상태 화면

- **L325와 L328의 문구·동작 불일치:** 완료 화면은 "자정이 지나면 새 카드를 뽑을 수 있어요"라고 안내합니다. 하지만 바로 아래 `처음부터` 버튼으로 즉시 다시 뽑을 수 있고, 뽑은 기록도 저장하지 않습니다. 시제품 전용 버튼이라면 그 사실을 표시하거나 숨기는 편이 좋습니다. "오늘은 이미 뽑았어요" 상태도 정의가 필요합니다.
- **L328 버튼 노출 범위:** `처음부터`가 첫 화면을 포함한 모든 장면에 보입니다. 첫 화면에서는 눌러도 의미가 없습니다.
- **L398~404, L425 타이머 경합:** 카드를 고른 뒤 1.4초 안에 `처음부터`를 누르면 첫 화면으로 갔다가 카드 화면으로 다시 넘어갑니다. L425도 같은 구조입니다. `start()`에서 `clearTimeout`으로 취소해야 합니다.
- **L45 스크롤 잘림 위험:** `.scene`이 `justify-content: center`와 `overflow-y: auto`를 함께 씁니다. 결과 화면이 뷰포트보다 길어지면 위쪽 카드가 잘리고 스크롤로도 닿지 못할 수 있습니다. `justify-content: safe center`로 바꾸고, 작은 화면에서 확인이 필요합니다.
- **L169 고정 버튼 겹침:** `position: fixed`인 `처음부터`가 작은 화면에서 미션 박스 위로 겹칠 수 있습니다.
- **Empty·Loading·Error 영역:**
  - 데이터가 코드에 내장되어 있어 지금은 없어도 동작합니다. 이름 미입력도 L414에서 잘 처리하고 있습니다.
  - 카드 데이터를 서버에서 받게 되면 세 상태를 모두 새로 설계해야 합니다.

### 권장 작업 순서
1. **버그성 항목:** L169 폰트 누락, 타이머 경합, L45 스크롤 잘림을 먼저 고칩니다.
2. **토큰 추가:** `:root`에 스페이싱, 글자 크기, radius, 그림자, 컨트롤 높이 토큰을 추가합니다.
3. **값 치환:** 기존 토큰과 값이 같은 32건을 먼저 바꾸고, 스페이싱 값을 치환합니다.
4. **일러스트 정리:** 일러스트 전용 색은 시제품 방향이 확정된 뒤 정리합니다.
