## 3. 데이터

| 항목 | 내용 |
|---|---|
| 수집처 | Steam 스토어 — 세일 목록 `store.steampowered.com/search/results/?specials=1&infinite=1`, 게임 상세 `/api/appdetails` |
| 국가 · 언어 | `cc=kr`(원화) · `l=korean` |
| 범위 | 세일 중인 게임 **최대 500개** = **평가순(`sort_by=Reviews_DESC`) 250개 + 관련도순(기본 정렬) 250개**. 겹치면 하나만 남기므로 500개보다 적을 수 있다 |
| 수집 횟수 | **한 번만.** 앱은 Steam에 실시간으로 요청하지 않고 저장한 CSV만 읽는다 |
| 수집 속도 | 요청 사이 1.5~2.5초. 최대 약 510번 요청 × 약 2초 ≈ **17분**. 나눠 수집할 수 있다 |
| 중단 · 이어 받기 | `polite_get` 캐시로 이어 받는다. 다시 돌리면 이미 받은 페이지는 요청하지 않는다 |
| 거절 | 403 · 429 · 리다이렉트를 받으면 바로 멈춘다. 재시도 · 우회하지 않는다 |
| 제외 | DLC · 사운드트랙 · 번들(`type`이 `game`인 것만), **정가 0원**인 무료 게임, 개인정보 · 로그인 영역 · 이미지 파일. 할인가 0원(원래 유료인데 지금만 무료)은 **남긴다** |
| 약관 · robots.txt | 확인 기록은 데이터 카드 [data/README.md](../data/README.md)의 '수집처 후보와 탈락 이유' · '약관 4.C 판단' · '배포할 때 지킬 것' |
| 탈락한 수집처 | IsThereAnyDeal API(배포하면 약관의 "경쟁 앱 금지"에 걸림), SteamDB(약관에서 크롤링 금지) |

### 정렬을 이렇게 고른 이유 (2026-11-06 실제 확인)

- **최신 출시순**은 첫 50개 중 **49개가 리뷰 0개**였다(전부 전날 출시작). 평가 정보가 거의 없어서 뺐다.
- **`Reviews_DESC`는 "리뷰 많은 순"이 아니라 "평가(긍정 %) 좋은 순"**이었다. 첫 50개가 긍정 93~100%이고, 리뷰가 있는 게임만 나온다(7,944개). → "평가순"이라고 부른다.
- Steam 검색에는 "리뷰 많은 순" 정렬이 없다.
- **관련도순**은 Steam 세일 화면을 처음 열면 보이는 순서다. 기준은 Steam이 공개하지 않는다. → 데이터 카드에 그대로 밝힌다.
- 두 정렬을 합쳐서 평가가 좋은 게임과 평가가 다양한 게임이 함께 들어온다.

### 모을 칸

| 칸 | 어디서 | 빈 값 처리 |
|---|---|---|
| appid · 제목 · Steam 링크 | 세일 목록 | 빈 값 없어야 함 |
| 정가 · 할인가 · 할인율 | 세일 목록 | 빈 값 없어야 함 |
| 리뷰 수 · 긍정 % · 리뷰 등급 | 세일 목록 (리뷰 요약 툴팁) | 리뷰가 없으면 **리뷰 수 = 0, 긍정 % = 빈칸** (0%로 저장하지 않는다) |
| 운영체제 (Windows · Mac) | 세일 목록 | 둘 다 False일 수 있다(Linux 전용 등) |
| 한국어 지원 | 게임 상세 `supported_languages` | 상세 요청 실패 시 **빈칸("모름")** |
| 수집 출처 | 수집할 때 기록 | `평가순` / `관련도순` / `평가순+관련도순` |
| 수집 시각 | 수집할 때 기록 | ISO 형식 KST (`2026-11-06T16:30:00+09:00`) |

- **한국어 지원 판정:** `supported_languages`에서 HTML을 걷어 낸 뒤 "한국어"가 있으면 지원으로 본다. 인터페이스 · 자막 · 음성을 구분하지 않는다. 형식은 수집 1단계에서 실제 데이터로 다시 확인한다.

## 6. 하지 않는 것 (그리고 이유)

- **카테고리별 할인율(장르 · 출시 연도 · 퍼블리셔):** 워크북 공통 기능이지만 뺐다. 사용자는 결국 게임 하나를 고르는데, 카테고리 평균 할인율은 그 결정에 쓸모가 적다. 데이터 분석 수업용 기능에 가깝다고 판단했다.
- 역대 최저가 · 가격 변동 기록 · 할인 종료 시각: Steam에 없고, ITAD는 쓰지 않기로 했다.
- 다른 스토어(Epic · GOG 등)와의 가격 비교
- 데이터 자동 갱신, 로그인, 위시리스트
- Linux 필터, 한국어 음성 구분
- 게임 이미지 · 설명
