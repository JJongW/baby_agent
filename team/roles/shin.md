# 신 (PO) — 조장, 데이터, 노션

오늘 조의 판을 깔고, 회의록에서 이슈로, 이슈에서 보고로 흐름을 돌리는 사람.
업무 배정은 신이 한다. 배정을 바꾸려면 `team/tasks.csv`를 고쳐 PR로 올린다.

## 순서
1. (#1) 팀 도구 틀 PR 머지 → 조원에게 "pull 받고 claude 열기" 알리기
   협업자 초대는 4명 모두 수락돼 있다 (11/17 확인). **깃허브 토큰은 아무에게도 만들게 하거나 받지 않는다**
2. (#2) 노션 페이지 만들기. Claude Code에서 `/mcp` → notion → Authenticate 먼저
   (#14) 노션 읽기 통합 만들기 → 조 페이지에 연결 → 조원에게 `NOTION_TOKEN` DM (`team/docs/tokens.md`). **내 노트북에도 꼭** (서기의 `inbox` 가 이걸로 노션을 읽는다)
   깃허브에 `[스탠드업] 7조` 이슈 하나 만들기: `team github_link 로 스탠드업 링크 줘` → 화면에서 만들고 고정(Pin). 조원은 여기에 하루 끝 댓글을 단다
3. 조원 Lv1 연결 확인을 받는다 (모두 같은 답이 나오는지)
4. (#3) 회의록 → 이슈 (화면 공유로 모두 보기)
5. (#4) 백로그 + 우선 라벨 2개
6. 조원 PR이 올라오면 리뷰 1명 승인 확인 후 깃허브 화면에서 머지
7. 노션 서기: 점심, 시연 전, 하루 끝에 `/mcp__team__scribe` (조원이 깃허브에 남긴 `/시작` 댓글, PR, 머지, 스탠드업 댓글을 노션에 옮긴다)
8. 하루 끝: 서기 한 번 → 주간 진행 정리 + 내 스탠드업 댓글

## 바로 쓸 말
노션 협업 보드 (#2): 설계는 `team/docs/notion-board.md`. 그 파일의 "만드는 말"을 쓴다.

회의록 → 이슈 (#3):
(한 번에: `/mcp__team__meeting_to_issues`)
```
notion "회의록" DB 의 11/17 킥오프와 team 의 list_tasks 를 같이 보고, 할 일마다 깃허브 이슈를 만들려고 해.
표로 먼저 보여 줘: 제목("[T번호] 할 일"), 본문(완료 기준), 라벨(개발/디자인/PO), 담당자(tasks.csv 의 담당자).
좋다고 하면 할 일마다 team github_link(번호) 로 이슈 만들기 링크를 줘 (이슈는 내가 깃허브 화면에서 만든다).
"만들었어" 하면 team link_status 로 이슈를 찾아 링크를 notion "할 일" DB 의 같은 번호 줄 "이슈" 칸에 적어 줘.
```
노션 서기 (깃허브 → 노션): `/mcp__team__scribe`. `inbox` 에 나온 칸만 고치고, 다시 불러 "없음"을 보여 준다.
노션 배정 맞추기 (tasks.csv 가 바뀔 때마다): `/mcp__team__sync_board`.
직군 문서 옮기기 (조원 PR 이 머지되면):
```
team/docs/screens.md(또는 persona.md) 를 읽고 notion "직군 문서" 아래 "화면 구성안"(또는 "출시 공지") 페이지로 옮겨 줘. 먼저 보여 줘.
```
백로그 (#4):
```
team 의 progress 와 link_status(열린 이슈)로 MVP 우선순위 표를 만들어 notion "직군 문서" 아래 "백로그" 로 써 줘.
높은 2개 이슈를 알려 줘 ("우선" 라벨은 내가 깃허브 화면에서 붙인다). 먼저 보여 줘.
```
주간 진행:
```
team report 의 오늘 닫힌 이슈, 머지된 PR 로 notion "주간 진행" 에 "11/17" 정리. 먼저 보여 줘.
```

## 하지 말 것
- 노션 페이지 공유 범위를 조 밖으로 열지 않기
- 서기는 `inbox` 에 나온 것만 옮긴다. 조원 대신 스탠드업을 지어 쓰지 않기
- 조원을 노션 멤버(유료)로 올리거나, 노션 쓰기 토큰을 만들어 조원에게 주지 않기
