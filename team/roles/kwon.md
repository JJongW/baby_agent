# 권 (디자인) — 규칙, 테스트 3번, 화면 구성안

> **배정 초안 (조 회의 전)**: 아래 할 일과 순서는 도구 틀을 만들며 채운 예시예요. 조 회의에서 정해 `team/tasks.csv` 배정이 `확정`이 될 때까지 시작하지 않아요.

AI가 우리 조 규칙대로 움직이는지 확인하고 기록하는 사람.

## 순서
1. Lv1 연결 확인
2. (#9) `team/AGENTS.md` 규칙을 읽고 빠진 것, 애매한 것을 고친다 → 브랜치 `kwon/docs-team-rules` → PR
3. (#9) 테스트 3번을 돌리고 `team/docs/test-log.md`에 기록 (같은 PR이나 새 PR)
4. (#10) 화면 구성안 3개를 `team/docs/screens.md` 로 PR (노션 "직군 문서"에는 신이 옮긴다. 조원은 노션 게스트라 보기만)
5. 하루 끝 스탠드업
