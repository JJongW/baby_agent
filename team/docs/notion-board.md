# 노션 협업 보드 설계 — "7조 P2"

노션은 조원 누구든 열자마자 "지금 뭐가 진행 중이고, 내가 뭘 하면 되는지"가 보이는 곳이다.
깃허브(코드, 이슈, PR)와 team(할 일 배정, 명단)은 이미 있는 것을 쓰고, 노션은 그걸 **보기 좋게 모아 보는 판**이자 **상태를 바꾸는 곳**이다.

## 세 곳을 잇는 열쇠: 할 일 번호
| 곳 | 번호가 붙는 자리 | 누가 바꾸나 |
| --- | --- | --- |
| team `tasks.csv` | `번호` 칸 | 배정(줄, 할 일, 담당, 마감)의 원본. PO 가 PR |
| 깃허브 이슈 | 제목 앞 `[T3]` | PO 가 만들고, 닫기는 PR 머지 |
| 노션 할 일 DB | `번호` 속성 | 상태의 원본. 각자 Claude 로 **내 줄**의 상태, 이슈, PR 칸. 줄 추가, 담당, 마감은 PO 가 tasks.csv 에 맞춰 |

team 의 `notion_board` 가 노션을 읽어 "담당자가 내 줄에서 고칠 것"과 "PO 가 맞출 것"을 나눠 알려 준다.

## 페이지 구조
```
🐣 7조 P2                         (허브. 아이콘 🐣, 커버 은은한 단색)
├ 📌 콜아웃: 상태는 Claude 에게 말하면 내 줄이 바뀐다 ("9번 시작했어"). 배정은 레포 team/tasks.csv
├ ✅ 할 일 (DB)                   메인. 아래 보기 4개
├ ☀️ 스탠드업 (DB)                하루 끝 한 줄씩
├ 🗒 회의록 (DB)                  날짜별
├ 📈 주간 진행 (페이지)            PO 가 하루, 주 단위로 정리
└ 📁 직군 문서 (페이지)
   ├ 🧭 백로그 (PO)
   ├ 🎨 화면 구성안 (디자인 권)
   └ 📣 출시 공지, 페르소나 (디자인 어)
```

허브 첫 화면 배치: 콜아웃 → 할 일 보드(상태별) → 두 칸(왼쪽 📅 캘린더, 오른쪽 🔥 오늘 마감) → 스탠드업 오늘 보기 → 회의록, 주간 진행, 직군 문서 링크.

## ✅ 할 일 DB
| 속성 | 종류 | 값 |
| --- | --- | --- |
| 할 일 | 제목 | tasks.csv 의 할 일 |
| 번호 | 숫자 | tasks.csv 번호 (열쇠) |
| 상태 | 상태 | 할 일(회색), 진행 중(파랑), 완료(초록) |
| 담당 | 선택 | 신, 노, 윤, 권, 어 |
| 직군 | 선택 | PO(보라), 개발(파랑), 디자인(분홍) |
| 마감 | 날짜 | tasks.csv 마감 (올해) |
| 이슈 | URL | 깃허브 이슈 링크 |
| PR | URL | 깃허브 PR 링크 |

보기
| 보기 | 모양 | 설정 |
| --- | --- | --- |
| 📋 보드 | 보드 | 상태로 묶기, 카드에 담당, 마감 표시 |
| 📅 캘린더 | 캘린더 | 마감 기준 |
| 👥 사람별 | 보드 | 담당으로 묶기, 완료 숨김 |
| 🔥 오늘 마감 | 표 | 마감 = 오늘, 상태 ≠ 완료 |

## ☀️ 스탠드업 DB
| 속성 | 종류 | 값 |
| --- | --- | --- |
| 제목 | 제목 | `11/17 신` 모양 |
| 날짜 | 날짜 | |
| 사람 | 선택 | 신, 노, 윤, 권, 어 |
| 오늘 한 일 | 텍스트 | 한 줄 |
| 다음 할 일 | 텍스트 | 한 줄 |
| 막힌 것 | 텍스트 | 없으면 "없음" |

보기: ☀️ 오늘(갤러리, 날짜 = 오늘), 🗂 전체(표, 날짜 최신순). 각자 **자기 줄만** 만든다.

## 🗒 회의록 DB
속성: 제목, 날짜, 참석(다중 선택), 결정(텍스트). 본문에 회의록 전문. 첫 줄은 `11/17 킥오프` (`team/docs/kickoff-1117.md`).

## 만드는 말 (신, Claude Code 에서 notion 인증 뒤)
```
notion 의 조 페이지(링크: 붙여 넣기)를 team/docs/notion-board.md 설계대로 "7조 P2" 협업 보드로 꾸며 줘.
1) 할 일, 스탠드업, 회의록 DB 를 속성 그대로 만들고
2) 할 일 DB 에 team 의 list_tasks 13줄을 그대로 넣고 (번호, 상태, 담당, 직군, 마감 2026년)
3) 회의록 DB 에 11/17 킥오프 한 줄, 직군 문서 아래 하위 페이지 3개
4) 보기(보드, 캘린더, 사람별, 오늘 마감)는 만들 수 있는 만큼 만들고, 못 만든 건 내가 손으로 할 순서를 알려 줘
만들기 전에 페이지 구조와 DB 속성을 표로 먼저 보여 줘.
```

## 내 줄 맞추기 (각자, 할 일을 시작하거나 끝낼 때)
Claude 에게 "9번 시작했어"라고 말하거나 `/mcp__team__my_board` 에 내 이름. 표로 먼저 보여 주고, 확인하면 내 줄의 상태, 이슈, PR 칸만 고친다.

## 배정 맞추기 (tasks.csv 가 바뀌면, PO)
`/mcp__team__sync_board`. 노션에 없는 줄, 담당, 마감이 다른 줄을 표로 보여 주고 "맞춰" 하면 노션 쪽만 고친다. 이미 있는 줄의 상태는 담당자 몫이라 건드리지 않는다.

## team 이 노션을 읽게 하기 (PO, 한 번)
`team/docs/tokens.md`. 통합을 만들고 이 페이지 ••• → 연결에 추가해야 team 의 `notion_board`, `search_notion` 이 이 페이지를 본다.

## 갈아탈 신호
- 배정까지 노션에서 바꾸고 싶다는 요청이 계속 나오면: 배정 원본도 노션 DB 로 옮기고 tasks.csv 를 없애는 걸 검토 (team 은 노션과 깃허브를 읽기만)
