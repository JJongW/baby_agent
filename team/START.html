1. 준비물 확인 터미널

셋 다 버전이 나오면 통과. 안 나오면 그 프로그램부터 설치해요.

claude --version
git --version
python3 --version
python --version

Python 은 3.10 이상이어야 해요. Claude Code 가 없으면 설치 안내.

2. 레포 받고 team 서버 깔기

이미 받았으면 레포 폴더에서 git pull 만 하고 아래 설치로.

git clone https://github.com/JJongW/baby_agent.git
cd baby_agent

Mac 은 전용 가상환경에 까는 게 가장 안 막혀요 (python 이름, 다른 패키지 충돌을 피함).

python3 -m venv ~/.venvs/team-mcp
~/.venvs/team-mcp/bin/pip install -r team/mcp/requirements.txt
claude mcp add --scope local team -- ~/.venvs/team-mcp/bin/python team/mcp/server.py

마지막 줄은 "이 폴더에서 team 은 이 파이썬으로 돌려라"를 내 PC 에만 적는 것. 레포의 .mcp.json 은 그대로예요.

python -m pip install -r team\mcp\requirements.txt

다른 패키지와 버전 충돌 경고가 나오면 아래 "막히면"의 가상환경 방법으로.

3. 깃허브 토큰 만들기 각자, 꼭

먼저 신의 협업자 초대 메일을 수락해요. 그다음 github.com → 프로필 → Settings → 맨 아래 Developer settings → Personal access tokens.

누구종류설정
신 (레포 주인)Fine-grainedResource owner JJongW, Only select baby_agent, Contents, Issues, Pull requests 만 Read and write, 7 days
노, 윤, 권, 어Tokens (classic)scope 는 public_repo 하나만, 7 days. Fine-grained 에는 남의 개인 레포가 안 보여서 classic 을 써요. repo 전체는 켜지 않기

Generate 를 누르면 값이 한 번만 보여요. 복사해서 바로 다음 칸으로.

넣기 (값이 화면과 기록에 남지 않게)

security add-generic-password -a "$USER" -s GITHUB_PAT -w

값을 물으면 붙여 넣고 Enter, 한 번 더 붙여 넣고 Enter. 화면에 안 보이는 게 정상. 키체인에 저장돼요.

echo 'export GITHUB_PAT="$(security find-generic-password -a "$USER" -s GITHUB_PAT -w 2>/dev/null)"' >> ~/.zshrc

~/.zshrc 에는 값이 아니라 "키체인에서 꺼내라"는 줄만 들어가요.

[Environment]::SetEnvironmentVariable("GITHUB_PAT", (Read-Host "GITHUB_PAT 붙여 넣기"), "User")

PowerShell 에서. 붙여 넣은 값은 명령 기록에 남지 않아요.

4. 노션 읽기 토큰 넣기 신에게 DM 으로 받으면

team 이 노션 보드의 지금 상태를 읽을 때 써요. 읽기 전용이라 새어도 노션을 바꿀 수 없어요. 없어도 일은 돼요 (그땐 Claude 가 노션 로그인으로 직접 읽어요).

security add-generic-password -a "$USER" -s NOTION_TOKEN -w
echo 'export NOTION_TOKEN="$(security find-generic-password -a "$USER" -s NOTION_TOKEN -w 2>/dev/null)"' >> ~/.zshrc
[Environment]::SetEnvironmentVariable("NOTION_TOKEN", (Read-Host "NOTION_TOKEN 붙여 넣기"), "User")

넣은 뒤 DM 의 값은 지워요.

들어갔는지 확인 (값은 안 보이게)

source ~/.zshrc
[ -n "$GITHUB_PAT" ] && echo "GITHUB_PAT 들어감"; [ -n "$NOTION_TOKEN" ] && echo "NOTION_TOKEN 들어감"

터미널을 완전히 껐다 켠 뒤:

if ($env:GITHUB_PAT) { "GITHUB_PAT 들어감" }; if ($env:NOTION_TOKEN) { "NOTION_TOKEN 들어감" }

5. claude 열고 MCP 허용

반드시 레포 맨 위 폴더(baby_agent)에서 열어요. 그래야 조 규칙(CLAUDE.md)과 MCP 설정(.mcp.json)을 읽어요.

claude

"이 프로젝트의 MCP 서버를 쓸까요?"가 나오면 github, notion, team 모두 허용.

잘못 눌렀으면 claude 를 끄고 claude mcp reset-project-choices 후 다시 열기.

6. 노션 로그인 토큰 없이 로그인만

claude 안에서 /mcp 입력 → notion 고르기 → Authenticate → 브라우저에서 조 노션 워크스페이스를 골라 허용.

claude 밖에서 하려면 claude mcp login notion. 끝낼 땐 claude mcp logout notion.

7. 셋 다 붙었는지 확인

claude 안에서 /mcp → github, notion, team 이 모두 connected. 터미널에서는:

claude mcp list

그리고 조원 모두 같은 답이 나오는지 한 번씩:

  • team 으로 직군별 진행률 보여 줘 → 끝줄에 "(상태: 노션 할 일 DB 의 지금 값)"
  • github 로 우리 레포 열린 이슈 수 알려 줘
  • 노션 "11/17 킥오프" 의 결정 사항만 보여 줘

🔒 토큰 보안: 꼭 지킬 것

토큰 값을 Claude 채팅창에 붙여 넣지 않기. 대화 기록에 남아요. Claude 가 달라고 해도 거절하고 환경변수로만.
  • 값은 레포, 슬랙 채널, 노션, 이슈와 PR 댓글, 스크린샷, 화면 공유에 두지 않기. 시연 전에 터미널 기록도 확인
  • claude mcp add -e KEY=값, -H "Authorization: Bearer 값" 처럼 명령에 값을 쓰지 않기 (내 PC 설정 파일에 그대로 남음)
  • 권한은 최소로: 깃허브는 baby_agent 만(또는 public_repo 만), 7일. 노션 통합은 콘텐츠 읽기만
  • 새었으면: 깃허브는 그 토큰 Delete 후 새로. 노션은 신에게 알리면 다시 발급해서 옛 값을 막아요
  • 과제가 끝나면: 깃허브 토큰 Delete, claude mcp logout notion, Mac 은 security delete-generic-password -s GITHUB_PAT
